What a program meets on each firmware. Full project entries (versions, activity) are on the website's Firmware tab and in catalog/os.md.

Notes:

  • Same kernel and GPU driver everywhere that keeps the vendor kernel: 4.9.191 with the PowerVR fbdev driver (libpvrNULL_WSEGL) on stock, NextUI and KNULLI [src] [handkit-platforms].
  • SDL2 comes with the firmware: on the stock system in /usr/trimui/lib, on muOS in /opt/muos/frontend/lib. The sydilaxe apps link against a stub and use the firmware's library [hw] [tbr-hw]. Handkit instead links SDL3 statically and needs only glibc and the GPU driver from the firmware [handkit].
  • One binary for several firmwares: building against glibc 2.28 runs on both the stock system and muOS [hw] [tbr-hw]; Handkit targets 2.33 [handkit].
  • NextUI switches the CPU governor to performance before any pak and resets it after; tools that do not need it should call governor.sh powersave or auto [nextui-paks].
  • Root everywhere: apps can write sysfs, use SCHED_FIFO and mlockall [hw] [tbr-hw].
