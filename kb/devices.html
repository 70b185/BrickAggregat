All from [tbr-hw], which lists more (Wi-Fi, charger, colour temperature) with a source per line.

Controller

On the stock system the built-in controller ("TRIMUI Player1") reports as an Xbox 360 pad (USB 045e:028e), so SDL maps it without a custom mapping; F1, F2 and HOME need extra handling [src] [handkit-platforms]. muOS uses its own input daemon with different button numbers ("muOS-Keys") [src] [handkit-platforms]. A user-space input daemon for the TrimUI family is in [trimui-inputd]. Per-firmware button numbers: [tbr-input].

Graphics

The GPU is driven through the vendor fbdev driver with no window system; EGL takes native window 0 [src]. OpenGL ES and Vulkan (VK_KHR_display) both ran on a Brick Pro under NextUI [hw] [handkit-platforms].
